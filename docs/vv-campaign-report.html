  • V12 BLE : PASS (contrôleur monté, app companion fonctionnelle).

Findings — backlog firmware

Tracés dans geophones-firmware/doc/test-bench-to-production.md.

  • TX CDC non-bloquante → porter en production (moyen).
  • START/STOP idempotents BLE → correctif contrôle app (haut).
  • Jauge batterie fausse : sous-estime (74 % à 7,57 V pleine) + glitches (moyen).
  • Gel sous charge (USB-pendant-acquisition, test-only) — à confirmer non-latent (haut).
  • Écriture SD open+close par record → keep-open + fsync périodique (bas).
  • Transfert CDC : corruption en transit (prouvé 3× : md5 différents) → CRC + retry sur GET, sans perte (moyen).

Conclusion & suites

GO pour le design — flotte homogène, saine, aucun FAIL. Suivis : correctifs firmware (backlog) ; compléter V3/V5/V14 ; statuer sur CG0-000008 ; calibration ANT (StationXML/SID) avec le géophysicien.
